## Описание проекта

В рамках второй лабораторной работы реализовано серверное приложение на базе **ASP.NET Core Web API**, предоставляющее REST API для выполнения базовых CRUD-операций над доменными сущностями и получения результатов аналитических выборок.

### Хранение данных:
* Хранение данных организовано в оперативной памяти через сервис `InMemStore`, зарегистрированный в DI-контейнере с жизненным циклом **Singleton**.
* При старте приложения хранилище инициализируется тестовыми данными (10 категорий, 10 клиентов, 10 изделий, 12 заказов).

### Реализованные CRUD-контроллеры:
Контроллеры поддерживают стандартные HTTP-методы (GET, POST, PUT, DELETE) и возвращают корректные статус-коды (200 OK, 201 Created, 204 NoContent, 400 BadRequest, 404 NotFound):
* `ClientsController` (`/api/clients`) — управление клиентами химчистки.
* `CategoriesController` (`/api/categories`) — справочник категорий изделий и стоимости чистки.
* `ItemsController` (`/api/items`) — управление изделиями с валидацией существования категории.
* `OrdersController` (`/api/orders`) — управление заказами с валидацией существования клиента, изделия и установкой дат.

### Аналитический контроллер (`AnalyticsController`):
Предоставляет результаты бизнес-запросов из первой лабораторной работы:
1. `GET /api/analytics/orders-in-progress` — заказы в обработке, упорядоченные по дате приёма.
2. `GET /api/analytics/top-clients` — определение Топ-5 клиентов, сдавших наибольшее количество изделий за указанный период.
3. `GET /api/analytics/clients-with-longest-orders` — клиенты с максимальным сроком выполнения заказа, отсортированные по ФИО.
4. `GET /api/analytics/categories-popularity` — Топ-5 наиболее и наименее популярных категорий изделий за последний год.
5. `GET /api/analytics/top-spending-client` — клиент, принесший наибольшую сумму выручки за всё время работы химчистки.

## Запуск проекта и тестов (из корневой папки проекта)

1. **Запуск Web API сервера:**
```bash
dotnet run --project XumChustka/XumChustka.Api/XumChustka.Api.csproj
```
После запуска эндпоинты доступны по адресу: `https://localhost:<порт>/api/...`.

2. **Запуск модульных тестов:**
```bash
dotnet test XumChustka/XumChustka.sln
```
